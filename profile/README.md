Every October, we build a free, community-owned library of security tips, guides, translations and labs that anyone can use, with a special focus on communities across Africa.

**Don't just learn cybersecurity. Contribute to it.** No experience needed: your first contribution takes 5 minutes in your browser.

### How to take part

| Time | What you do |
|---|---|
| **2 minutes** | Share a security tip on social media with **#CyberSecTOBER** |
| **5 minutes** | Add one security tip to the project, right in your browser |
| **15–60 minutes** | Pick a challenge and build a guide, translation, checklist, lab or tool |

Every merged contribution earns points and verified badges you can add to your GitHub profile and LinkedIn. Full step-by-step instructions are in the [project README](https://github.com/CyberSecTober/Cybersectober#readme).

### Tracks

🔐 **Cyber Awareness**: phishing, scams, passwords, MFA
🌐 **Web & API Security**: checklists, OWASP API Top 10, hands-on labs
🤖 **AI Security**: prompt injection, RAG and agent security
🌍 **Africa & Local Communities**: Yoruba, Igbo, Hausa, Pidgin and Swahili translations, and guides for traders, SMEs and schools
