Every October, people share cybersecurity tips, lessons, research, guides, stories, checklists and resources.

But what happens to that knowledge when October is over?

**CyberSecTOBER turns meaningful cybersecurity content into open-source knowledge that anyone can access, learn from and contribute to.**

> Write a cybersecurity awareness post.<br>
> Create a guide.<br>
> Share a lesson.<br>
> Build a checklist.<br>
> Translate a resource.<br>
> Create a lab.<br>
> Document what you know.

If it's meaningful, useful and educational, contribute it.

<p align="center"><b>One repository.<br>Thousands of contributors.<br>Knowledge anyone can access.</b></p>

### Come for knowledge, leave some behind

Need a cybersecurity tip for your next post, a template for a guide or checklist, or a resource in your own language? You can always come back to this repository. Every contribution makes it more useful for the next person who needs it.

- **Security tips** ready to share: [awareness/tips.md](https://github.com/CyberSecTober/Cybersectober/blob/main/awareness/tips.md)
- **Templates** for guides, checklists, translations, labs and tools: [templates/](https://github.com/CyberSecTober/Cybersectober/tree/main/templates)
- **Translations** in Yoruba, Igbo, Hausa, Pidgin and Swahili: [community/translations/](https://github.com/CyberSecTober/Cybersectober/tree/main/community/translations)

### How to take part

| Time | What you do |
|---|---|
| **2 minutes** | Share a security tip on social media with **#CyberSecTOBER** |
| **5 minutes** | Add one security tip to the project, right in your browser, with no installs |
| **15–60 minutes** | Pick a challenge and build a guide, translation, checklist, lab or tool |

No experience needed. Step-by-step instructions are in the [project README](https://github.com/CyberSecTober/Cybersectober#readme).

### Tracks

| Track | What it covers |
|---|---|
| **Cyber Awareness** | Phishing, scams, passwords, MFA |
| **Web & API Security** | Checklists, OWASP API Top 10, hands-on labs |
| **AI Security** | Prompt injection, RAG and agent security |
| **Africa & Local Communities** | Local-language translations, and guides for traders, SMEs and schools |
